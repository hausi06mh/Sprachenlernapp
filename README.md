# Lumi Romanian v9

Korrekturen:
- Lumi ist direkt in HTML/JavaScript eingebettet und kann nicht mehr durch einen fehlenden Asset-Pfad verschwinden.
- Wort-Hilfen zeigen niemals mehr ersatzweise die komplette Satzübersetzung.
- Geschichten zeigen in der Lösung Rumänisch und die passende deutsche Antwort.
- Schreibaufgaben akzeptieren Satzzeichen, fehlende Diakritika und kleine Tippfehler toleranter.
- Fehlerhafte Wörter landen in einer Wiederholungswarteschlange und erscheinen in passenden Lektionen erneut.
- Kurze Grammatikhinweise erklären ausgewählte Formen.
- Hörübungen starten nur nach einem bewussten Tipp auf den Lautsprecher.

Alle Dateien direkt über die bestehende GitHub-Version hochladen. Danach einmal mit `?v=9` öffnen.
